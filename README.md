# overview
Instructions to create an environment to run the different codes

# Installation
1. Download miniconda from https://docs.conda.io/en/latest/miniconda.html
2. Install with `bash Miniconda3-latest-Linux-x86_64.sh`
3. Create a conda environment. You may choose your preferred python VERSION. The codes are known to work with version 3.13, but this may change in the future. Run: `conda create --name my_env python=VERSION`
4. Activate the environment: `conda activate my_env`
3. run `sudo bash install_with_sudo.sh`
4. run `bash install.sh`

(replace {INSTALL_PATH} with the actual path where you cloned this repository)
